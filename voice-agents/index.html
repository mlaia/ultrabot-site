The pipeline

Three models in a row.
Each one adds delay.

We stream every stage and start speaking at the first sentence, not after the whole reply.

01

Turn detection

Deciding when the user is done. Too early interrupts, too late feels slow, so we tune it per language.

02

Streaming speech-to-text

Chosen by accuracy on your vocabulary and streaming delay. Unclear fragments are dropped, not answered.

03

The agent

A model with tools for booking, lookup or updates, released one sentence at a time.

04

Text-to-speech

Voices compared on naturalness, pronunciation and time to first audio, with a fallback if one is slow.

05

Barge-in

The agent pauses when the user speaks. A cough resumes playback; a real request stops the turn.

06

Speech-to-speech models

Nova Sonic or realtime models listen and speak in one step. We compare them with a pipeline before choosing.

Before we start

Good questions. Straight answers.

How fast can a voice agent respond?

It depends on the channel, models and network. We measure each stage on your setup and stream all of them, so the agent starts speaking at its first sentence instead of after the full reply.

Can we use ElevenLabs?

Yes, ElevenLabs is one of the voices we integrate and compare. For personal or health data, we check the provider's data terms first and use a provider with the right contract where needed.

Can a voice agent work over the phone?

Yes, through Amazon Connect, Twilio or a SIP provider. Phone audio is narrower-band and noisier than web audio, so recognition and turn detection are tested on real calls.

What happens when the agent cannot help?

It says so and hands off: transfer to a person, a callback request, or a message with a summary of the conversation so far, depending on the channel.

Do you record the calls?

Only if you decide to and the user is informed. Many of our designs keep no audio or transcripts at all and log only which tools were used.
